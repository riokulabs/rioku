# Stage-2 Master Decision List

> The user's inbox for decisions surfaced during stage-2 plan execution.
>
> Entries are appended by `make decisions-sync` after each sub-PR merges,
> sourced from `decisions-needed.md` files in active plan worktrees.
>
> Format spec: see `contrib-docs/templates/decisions-needed.md`.
> IDs are monotonic. Plan 13 close-out blocks the final integration if any
> item's status is `open`.
